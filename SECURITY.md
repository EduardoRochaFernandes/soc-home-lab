# Security Policy

## Scope

This is a **home lab and educational project**. It is not intended to be deployed in production environments.

If you find a vulnerability in:
- A **third-party tool** used in this project (Wazuh, ELK, Suricata, TheHive, MISP) — please report it to the respective upstream project
- A **script or configuration** in this repository that could cause harm if followed — please follow the process below

## Reporting a Vulnerability

Open a **private GitHub Security Advisory** on this repository:

1. Go to **Security → Advisories → New draft security advisory**
2. Describe the issue, the impact, and steps to reproduce
3. This is a student project, so responses are best-effort

Please do **not** open a public issue for security vulnerabilities.

## Legal Disclaimer

All attack techniques, tools, and simulations documented in this repository are intended for use in **isolated, offline lab environments only**.

- Do NOT use these techniques against systems you do not own or have explicit written permission to test
- The author assumes no responsibility for misuse of any information contained in this repository
- This project is published for educational and defensive security purposes only
